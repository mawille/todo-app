# Todos

Kleine Todo-App fürs Handy (Web-App/PWA): Todos mit Priorität, Deadline, Kategorie und Notiz, anpassbares Aussehen mit Dunkelmodus. Läuft offline, die Daten bleiben auf dem Gerät.

**App öffnen:** https://mawille.github.io/todo-app/

Auf den Homescreen legen:
- Android (Chrome): Menü ⋮ → „Zum Startbildschirm hinzufügen“
- iPhone (Safari): Teilen → „Zum Home-Bildschirm“

Schnelleingabe: `Mama anrufen !hoch #Privat @morgen`

## Wochenteller

Mahlzeitenplaner im Ordner `wochenteller/`: Gerichte pro Tag eintragen, Zutaten je Gericht speichern und automatisch eine Einkaufsliste für die Woche zum Abhaken erzeugen. Gespeicherte Gerichte lassen sich mit einem Tipp erneut übernehmen. Läuft ebenfalls offline, die Daten bleiben auf dem Gerät.

**App öffnen:** https://mawille.github.io/todo-app/wochenteller/

Zutaten eine pro Zeile eingeben, z. B. `500 g Spaghetti`. Gleiche Zutaten aus mehreren Gerichten werden auf der Einkaufsliste zusammengezählt.

Sachen ohne Gericht (z. B. `Klopapier` oder `200 g Bacon`) direkt in der Einkaufsliste über das Eingabefeld hinzufügen. Sie gelten für die angezeigte Woche und lassen sich mit dem ✕ wieder entfernen.
