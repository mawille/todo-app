# Todos

Kleine Todo-App fürs Handy (Web-App/PWA): Todos mit Priorität, Deadline, Kategorie und Notiz, anpassbares Aussehen mit Dunkelmodus. Läuft offline, die Daten bleiben auf dem Gerät.

**App öffnen:** https://mawille.github.io/todo-app/

Auf den Homescreen legen:
- Android (Chrome): Menü ⋮ → „Zum Startbildschirm hinzufügen“
- iPhone (Safari): Teilen → „Zum Home-Bildschirm“

Schnelleingabe: `Mama anrufen !hoch #Privat @morgen`
